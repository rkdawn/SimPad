SimPad 1.0.0 / 模拟平板
GPL-3.0-only. The complete GPL, Apache-2.0 and LGPL license texts accompany this APK.

This module simulates a tablet identity inside WeChat, DingTalk and WeCom on a phone.
It does not change the global device model or claim support for every target app version.
The user-validated pre-startup, original-call and chat exception behavior is retained.
The standalone B hook and module-initiated shared result-cache writes remain removed.
Unchanged read-only installed APK digests may be reused after metadata checks.
Module upgrades still recheck content; unchanged code/rules may reuse the method plan.
The normal package, active-code, loader and before/after input checks are preserved.
The main build uses API34+ StackWalker for chat-package classification, falling back to
Thread stack traces on older systems or ordinary/linkage failure. The legacy-chat build
uses Thread stack traces throughout. No per-call chat result, timing or logging is cached.
