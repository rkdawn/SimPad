# 微信适配

SimPad 1.20 的版本规则按 Google Play 微信（`com.tencent.mm`）的版本名和构建号共同匹配：

| 微信版本 | 设备判断 | 历史登录页 |
|---|---|---|
| 8.0.79／3183 | 保留内层判断 | 保留旧行为 |
| 8.0.80／3200 | 外层判断，原缓存命中时也生效 | 初始化后检查原生按钮 |
| 8.0.80／3202 | 与 3200 相同，经该构建的方法关系对照 | 初始化后检查原生按钮 |

历史登录页仅在微信已给目标按钮绑定点击事件时恢复其可见性。不创建登录入口，不更改认证结果。静态适配不等同于真机验收：请分别验证 3202 正常登录、主动退出后重新登录，以及 3202 直接回退 3200 时的入口显示。其他渠道和构建未验证。

安装后请彻底结束微信再重新打开，不要同时启用其他修改平板身份的模块。
