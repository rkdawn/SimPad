# 微信平板适配同步：1.20

相比 1.10，本版增加 Google Play 8.0.80／3202 规则，并更新 3200、3202 历史登录页行为。只集成微信适配时，无需同步其他应用或更换模块框架。

- **版本与定位**：`WeChatProfiles.kt` 按版本名和构建号匹配。3183 使用内层设备判断；3200、3202 使用缓存优先的外层判断。仍须通过 `MethodGraph.kt` 的方法、字段和调用关系校验，未知版本不套用相邻构建的描述符。
- **缓存**：`HookPolicy.kt` 更新微信独立的规则版本。`HookEntrance.kt` 在冷启动解析和缓存命中时向 `PlanBinder.kt` 传入同一宿主版本。只使旧微信计划失效，不写微信共享结果缓存，不影响钉钉或企业微信。
- **登录页**：仅在 3200、3202 上追加历史登录页初始化后回调。保留原方法和其余拦截链，成功返回后查找指定按钮；仅当按钮已绑定点击监听且不可见时恢复显示。不创建监听、不触发点击、不修改认证。3183 保留原设备及登录入口两个回调。
- **回归**：覆盖 3183、3200、3202、非匹配版本、冷／热计划绑定、原调用次数与异常、按钮缺失／无监听／已显示，以及非微信缓存隔离。集成方仍需独立验收登录、退出后重登、聊天输入及后台消息。

版本范围见[微信适配](WECHAT-COMPATIBILITY.md)。不要同时启用两个平板实现。
