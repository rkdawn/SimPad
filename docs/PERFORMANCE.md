# 技术说明

## 平板身份适配

模块在目标应用进程内处理设备类型及平板登录判断，保留原方法调用与聊天输入区域的兼容逻辑，不修改系统全局机型。

## 启动与定位

业务Hook在应用启动阶段安装，并在原启动方法执行后复核输入与加载器。方法定位计划绑定宿主代码身份和规则版本，输入变化时不复用失效记录。

## 缓存

只读安装APK的摘要可在文件及安装身份未变化时复用，减少重复读取。安装更新、可写输入或动态代码变化仍进行相应校验。

## 调用栈

Android API34及以上按批读取调用栈类名，命中聊天包后结束匹配；其他情况使用系统兼容路径。每次调用单独分类，不缓存线程的聊天状态。
